# Windows UI 与 INI 设置

## 程序目录与数据布局

LNPlayer 优先采用便携式目录布局，配置和用户数据跟随程序目录：

```text
LNPlayer/
├─ LNPlayer.exe
├─ FFmpeg / Qt 运行库
└─ Data/
   ├─ settings.ini
   ├─ Screenshots/
   ├─ Cache/       # 需要缓存时按需创建
   └─ Logs/        # 需要文件日志时按需创建
```

- 配置文件固定为 `Data/settings.ini`，使用 Qt `QSettings::IniFormat`。
- `Data` 目录可写时，所有应用配置与应用数据优先写入该目录。
- 如果程序安装在 `Program Files` 等不可写目录，Windows 会拒绝普通用户写入；此时才回退到 `QStandardPaths::AppLocalDataLocation/Data`（当前用户 Local App Data 下的 LNPlayer 专属数据目录）。这是保证标准安装位置可运行所需的例外，不会为了方便而默认把数据散落到用户目录。
- NSIS 安装包默认安装到当前用户的 `%LOCALAPPDATA%\\Programs\\LNPlayer`，使程序目录数据可写。当前 CPack NSIS 模板仍设置 `RequestExecutionLevel admin`，因此安装器本身仍可能触发 UAC；这与播放器运行时数据目录权限是两件事，后续应单独调整安装器提权级别。
- 设置窗口“常规”页展示实际 INI 路径，并提供打开配置目录入口。
- 截图默认目录为数据目录下的 `Screenshots`；用户也可以在设置中指定其他目录。
- 播放列表、最近播放、播放位置、书签、媒体偏好等目前集中存储在 INI 中，不额外创建数据库或散落文件。
- 缓存、日志、缩略图等只有在相应功能真正实现后才按需创建子目录，不预先创建空目录。

## 注册表与 Windows 集成

- 正常运行时，播放器设置只读写 INI，不使用注册表保存应用偏好。
- 仅保留一次性旧版本迁移：首次启动时尝试读取旧版 `HKCU\\Software\\LNPlayer\\LNPlayer`，只补入 INI 中不存在的键，然后记录迁移标记。后续启动不再读取注册表。
- Windows 安装包只在**当前用户**范围注册文件类型和 ProgID，写入 `HKCU\\Software\\Classes` 与 `HKCU\\Software\\RegisteredApplications`，不写 HKLM，不影响其他 Windows 用户，也不要求管理员权限。
- 卸载时只移除 LNPlayer 自己注册的 ProgID、OpenWith 项和 RegisteredApplications 项，不修改 Windows 当前默认应用选择。
- Windows 10/11 不允许普通桌面程序静默接管用户默认应用。安装后用户仍需在 Windows“默认应用”设置中选择 LNPlayer；播放器设置页使用 `ms-settings:defaultapps?registeredAppUser=LNPlayer` 直达 LNPlayer 的默认应用设置页。
- 便携版不主动修改系统文件关联；用户可在文件“打开方式”中选择 LNPlayer。

## 支持的视频文件格式

安装包注册以下扩展名为 LNPlayer 可打开的视频格式：

`.mp4`、`.mkv`、`.mov`、`.avi`、`.webm`、`.wmv`、`.flv`、`.mpeg`、`.mpg`、`.m4v`、`.ts`、`.mts`、`.m2ts`、`.3gp`、`.3g2`、`.vob`、`.ogv`、`.mxf`、`.asf`、`.f4v`、`.divx`、`.mpe`、`.mpv`。

这些格式应与打开文件、拖放和文件夹递归扫描使用的扩展名列表保持一致。注册“可打开”不代表每个文件内部编码均受支持，最终仍由 FFmpeg demuxer/decoder 能力决定。

## 设置面板

| 面板 | 内容 | 应用方式 |
|---|---|---|
| 常规 | INI 路径、打开配置目录、Windows 默认应用设置入口、支持格式说明 | 只读信息与系统设置入口 |
| 播放 | 记住每个视频的播放位置、播放结束自动下一项、默认播放速度（0.25×–4×）、循环模式（关闭/列表/单项）、随机播放 | 保存后立即应用；循环/随机状态沿用播放列表持久化 |
| 界面 | 全屏控制栏隐藏时间、OSD 时长/位置、播放列表侧栏、窗口置顶、中键行为、滚轮行为（音量/±5 秒 Seek/画面缩放）、右键拖动手势 | 保存后立即应用 |
| 视频 | 原始比例/16:9/4:3/拉伸、亮度、对比度、饱和度、色调、锐化、降噪、灰度 | 保存后立即应用 |
| 字幕 | 字幕启用状态、同名字幕自动匹配、默认延迟、字体、字号、颜色、垂直位置 | 保存后立即应用；媒体级轨道/外挂字幕偏好仍独立保存 |
| 快捷键 | 播放控制、全屏、Seek、逐帧、音量、播放列表、速度、截图、静音等 | 保存前检查冲突 |
| 截图 | 默认保存目录、PNG/JPEG/BMP 格式 | 保存后用于下一次截图 |
| 性能 | 当前渲染器、视频分辨率、解码选择说明 | 只读状态 |

“恢复默认”仅重置设置窗口中可编辑的偏好；取消窗口不会写入这些设置。

## 设置窗口交互布局

- 设置窗口采用左侧分类导航、右侧滚动内容页，避免设置项增加后横向 Tab 挤压。
- 当前分类为常规、播放、界面、视频、字幕、快捷键、截图、性能；页面切换不重建控件，当前编辑状态保留。
- 设置窗口最小尺寸调整为 820×600；窄屏时右侧页面可独立滚动。
- 分类导航统一选中、悬停和普通状态，保持播放器深色主题。
- 这次只调整设置窗口的信息架构和导航，不将尚未实现的 PotPlayer 高级选项伪装成可用功能。

## INI 键约定

- `Config/*`：配置迁移与版本信息。
- `Playback/*`：通用音量。
- `Video/Playback/*`：视频播放行为，包括记住播放位置与自动播放下一项。
- `Video/UI/*`、`Video/Window/*`：窗口与界面。
- `Video/Display/*`、`Video/Filter/*`：画面显示和滤镜。
- `Video/Subtitle/*`：字幕启用状态、默认样式和时间偏移。\n- `Video/Mouse/*`：中键、滚轮和右键拖动行为。
- `Video/Shortcuts/*`：快捷键。
- `Video/Screenshot/*`：截图目录和格式。
- `Video/RecentFiles`、`VideoPlaylist/*`：最近播放与播放队列。
- `Video/Media/*` 及按媒体哈希生成的键：媒体独立播放位置、书签和字幕偏好。

设置键继续采用原有分组路径，便于手工编辑 INI 和后续增加版本迁移。

## 当前限制与验收

- 源码已将设置文件位置切换到程序目录下的 `Data/settings.ini`，并在程序目录不可写时回退到 `QStandardPaths::AppLocalDataLocation/Data`。
- 安装包文件关联已改为当前用户范围，不写 HKLM；Windows 默认应用选择仍由系统设置界面控制。
- 旧版注册表迁移仅用于兼容升级，不作为新版本配置存储方式。
- 仍需 Windows/MSVC/Qt 构建与实机验收：可写目录便携运行、Program Files 安装回退、升级迁移、卸载清理、Windows 10/11 默认应用选择，以及每种扩展名双击启动。
- 本轮未运行 Windows 构建、CTest 或 CI。
- 音量拖动期间采用 300 ms 防抖写入 INI，窗口关闭时同步保存最终值。
- 字幕启用状态在 Player 初始化及设置窗口保存后同步到 Core。
- 画面滤镜设置保存与加载范围已统一；降噪范围固定为 0–1。
- 性能页目前是状态展示，不提供尚未实现的 GPU 使用率或丢帧统计开关。
- 设置窗口已改为左侧分类导航和右侧滚动页面；Windows 运行时的布局、焦点和缩放仍待验收。\n- 播放设置已接入循环模式和随机播放；界面设置已接入滚轮调节音量、5 秒 Seek、画面缩放三种行为。
