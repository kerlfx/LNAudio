# Windows UI 与 INI 设置

## 设置文件

Windows 版本统一使用 Qt `QSettings::IniFormat`，不再将新设置写入注册表。

- 文件名：`settings.ini`
- 目录：`QStandardPaths::AppConfigLocation`
- Windows 上由 Qt 根据 `LNPlayer` organization/application identity 解析到当前用户的应用配置目录。
- 设置窗口“常规”页显示实际文件路径，并提供“打开配置目录”。
- 首次启动时读取旧版 `HKCU\\Software\\LNPlayer\\LNPlayer` 配置；只迁移 INI 中不存在的键，完成后写入 `Config/RegistryMigrationCompleted=true`。已有 INI 值优先，不覆盖用户在 INI 中的修改。
- 播放列表、媒体书签、播放位置、音量、快捷键和媒体偏好继续使用原有键名，迁移时不改变数据模型。

## 设置面板

播放器设置窗口目前包含：

| 面板 | 内容 | 应用方式 |
|---|---|---|
| 常规 | INI 路径、打开配置目录 | 只读信息与目录入口 |
| 播放 | 记住每个视频的播放位置 | 下一次媒体切换/启动生效 |
| 界面 | 全屏控制栏隐藏时间、OSD 时长/位置、播放列表侧栏、窗口置顶、中键行为、右键拖动手势 | 保存后立即应用 |
| 视频 | 原始比例/16:9/4:3/拉伸、亮度、对比度、饱和度、色调、锐化、降噪、灰度 | 保存后立即应用 |
| 字幕 | 字幕启用状态、同名字幕自动匹配、默认延迟、字体、字号、颜色、垂直位置 | 保存后立即应用；媒体级轨道/外挂字幕偏好仍独立保存 |
| 快捷键 | 播放控制、全屏、Seek、逐帧、音量、播放列表、速度、截图、静音等 | 保存前检查冲突 |
| 截图 | 默认保存目录、PNG/JPEG/BMP 格式 | 保存后用于下一次截图 |
| 性能 | 当前渲染器、视频分辨率、解码选择说明 | 只读状态 |

“恢复默认”仅重置设置窗口中可编辑的偏好；取消窗口不会写入这些设置。

## INI 键约定

- `Config/*`：配置迁移与版本信息。
- `Playback/*`：通用音量。
- `Video/Playback/*`：视频播放行为。
- `Video/UI/*`、`Video/Window/*`：窗口与界面。
- `Video/Display/*`、`Video/Filter/*`：画面显示和滤镜。
- `Video/Subtitle/*`：字幕启用状态、默认样式和时间偏移。
- `Video/Shortcuts/*`：快捷键。
- `Video/Screenshot/*`：截图目录和格式。
- `Video/RecentFiles`、`VideoPlaylist/*`：最近播放与播放队列。
- `Video/Media/*` 及按媒体哈希生成的键：媒体独立播放位置、书签和字幕偏好。

设置键继续采用原有分组路径，便于手工编辑 INI 和后续增加版本迁移。

- 画面滤镜设置保存与加载范围已经统一；降噪范围固定为 0–1，与当前 Core/Renderer 参数约定一致。
- 性能页目前是状态展示，不提供尚未实现的 GPU 使用率或丢帧统计开关。
